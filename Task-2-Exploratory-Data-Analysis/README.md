# 📊 Exploratory Data Analysis (EDA)

## 📌 Objective

This project performs Exploratory Data Analysis (EDA) on a dataset using Python to uncover patterns, trends, correlations, and outliers.

---

## Features

- Load dataset
- Dataset overview
- Summary statistics
- Missing value detection
- Histograms
- Boxplots
- Correlation heatmap
- Pair plot
- Generate analysis report

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Project Structure

```
Task-2-Exploratory-Data-Analysis/
│
├── dataset.csv
├── eda_analysis.py
├── report.txt
├── requirements.txt
├── README.md
└── output/
```

---

## How to Run

```bash
pip install -r requirements.txt
python eda_analysis.py
```

---

## Output

The project generates:

- Histogram
- Boxplots
- Correlation Heatmap
- Pair Plot

All graphs are saved inside the **output/** folder.
