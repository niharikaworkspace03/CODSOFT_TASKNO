# Data Cleaning & Preprocessing using Python

This project demonstrates the process of cleaning and preprocessing a dataset using **Python** and **Pandas**. The goal is to prepare raw data for analysis by handling missing values, removing duplicate records, correcting inconsistent data, and saving the cleaned dataset.

---

## Objective

- Import a dataset using Python.
- Inspect the dataset structure.
- Identify missing values and duplicate records.
- Handle null values.
- Remove duplicate entries.
- Correct inconsistent data.
- Save the cleaned dataset as a new CSV file.

---

## Technologies Used

- Python 3.12
- Pandas
- VS Code

## Dataset

The project uses a CSV dataset (`dataset.csv`) containing sample records with missing values and duplicate entries for demonstrating data preprocessing techniques.

## Features

- ✅ Load CSV dataset
- ✅ Display dataset information
- ✅ Detect missing values
- ✅ Detect duplicate records
- ✅ Remove duplicate rows
- ✅ Fill missing values
- ✅ Clean text data by removing extra spaces
- ✅ Save cleaned data into a new CSV file

```bash

```



