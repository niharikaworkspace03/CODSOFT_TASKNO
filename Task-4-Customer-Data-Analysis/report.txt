============================================================
                     STUDENT DATA ANALYSIS
============================================================

Project Name:
Student Data Analysis using Python

Objective:
The objective of this project is to perform Exploratory Data Analysis (EDA)
on the Iris dataset using Python. The project analyzes the dataset,
generates statistical summaries, visualizes data through graphs, and
extracts meaningful insights.

------------------------------------------------------------
Tools & Technologies
------------------------------------------------------------

• Python 3
• Pandas
• NumPy
• Matplotlib
• Seaborn

------------------------------------------------------------
Dataset
------------------------------------------------------------

Dataset Used:
Iris Dataset

Number of Records:
150

Number of Features:
5

Features:

• sepal_length
• sepal_width
• petal_length
• petal_width
• species

------------------------------------------------------------
Data Analysis Performed
------------------------------------------------------------

• Loaded dataset
• Checked dataset information
• Verified missing values
• Generated descriptive statistics
• Performed exploratory data analysis
• Created multiple visualizations
• Saved cleaned dataset

------------------------------------------------------------
Visualizations Generated
------------------------------------------------------------

1. Species Count
2. Sepal Length Distribution
3. Sepal Width Distribution
4. Petal Length Distribution
5. Petal Width Distribution
6. Feature Means
7. Sepal Length by Species
8. Petal Width by Species
9. Scatter Matrix

------------------------------------------------------------
Key Insights
------------------------------------------------------------

• The dataset contains three Iris species.
• Petal measurements clearly distinguish the species.
• Sepal measurements show moderate variation.
• No missing values are present in the dataset.
• The generated visualizations help identify relationships
  between different flower measurements.

------------------------------------------------------------
Project Outcome
------------------------------------------------------------

The project successfully performs data analysis and visualization
using Python. Multiple high-quality PNG graphs are generated
automatically and stored inside the Output folder.
