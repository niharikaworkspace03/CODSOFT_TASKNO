# 📊 Student Data Analysis

A comprehensive **Student Data Analysis** project developed using **Python, Pandas, Matplotlib, and Seaborn**. This project performs exploratory data analysis (EDA) on the Iris dataset, generates multiple visualizations, and extracts meaningful insights from the data.

---

## 📌 Project Overview

The objective of this project is to analyze student-related data, perform statistical exploration, visualize important patterns, and generate informative reports through various charts and graphs.

---

## 🚀 Features

- Load and analyze dataset
- Perform data cleaning
- Handle missing values
- Generate descriptive statistics
- Visualize feature distributions
- Compare different categories
- Generate high-quality PNG graphs
- Save cleaned dataset automatically
- Create an output folder automatically

---

## 🛠 Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
