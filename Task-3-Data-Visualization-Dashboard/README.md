# 📊 Data Visualization Dashboard

A professional **Data Visualization Dashboard** developed using **Python, Matplotlib, and Seaborn** as part of the **CodSoft Data Analytics Internship (Task 3)**.

---

## 📌 Objective

Create meaningful visualizations to analyze the Iris dataset and present insights through different chart types.

---

## 🚀 Features

- Dataset Exploration
- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot
- Correlation Heatmap
- Pair Plot
- Combined Dashboard

---

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- NumPy
- VS Code

## ▶️ How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the program:

```bash
python visualization_dashboard.py
```

All generated images will be saved inside the **output** folder.
